# GUI 重构：macOS 磨砂玻璃分层布局

## Goal

抛弃现有「单列纵向流」布局，参照用户提供的 macOS 深色应用截图（ZCode 风格）的设计理念，将 GUI 重构为：侧边栏 + 主工作区的分层结构，采用深色画布、hairline 细边框、圆角卡片、半透明磨砂玻璃面板的 macOS 原生质感。只重排/重塑现有功能，不新增业务功能。

## Requirements

- R1 布局结构：左侧固定侧边栏（品牌区 + 导航 + 底部状态区），右侧主工作区；侧边栏顶部为 macOS 红绿灯留白且整条可拖拽。
- R2 视觉语言：深色画布 + 环境光渐变背景；面板/卡片使用半透明磨砂玻璃（backdrop-blur + 白色 alpha 表面）；hairline 边框（white alpha ~8%）；大圆角（12-16px）；保留珊瑚色 primary 作为 CTA。
- R3 首页（无结果时）：居中问候标题 + 大号玻璃输入卡片（URL 输入 + 生成按钮 + 模式行）+ 模式建议卡片行（摘要 / 全文 / 时间戳 / 自定义模板），点击卡片即切换模式，自定义卡片打开自定义模板弹窗。
- R4 结果态：主工作区顶部为紧凑工具条（URL 输入 + 模式分段 + 生成），下方为结果玻璃卡片（标题、badge、tabs、Markdown 渲染、操作按钮），功能与现 ResultPanel 完全一致。
- R5 设置改为侧边栏导航的独立视图（非弹窗），表单内容与现有设置一致（鉴权 / 字幕抓取两节），自动保存行为不变。
- R6 主题 token 化翻转：重定义 `index.css` 中 DESIGN token 值为深色玻璃系，使 shadcn 桥接变量与全部 UI 原语自动适配；不逐组件硬改颜色。
- R7 保留：Overlay 标题栏、mac 红绿灯适配、自定义模板弹窗、Toaster、全部既有交互与 lib/core 逻辑零改动。
- R8 窗口默认尺寸适度加宽以容纳侧边栏（minWidth 调整）。

## Acceptance Criteria

- [x] `pnpm check`（tsc + cargo check）与 `pnpm test` 通过。
- [x] 浏览器预览（vite dev）截图验证：侧边栏 + 首页 hero + 输入卡片 + 模式卡片呈现深色磨砂玻璃分层风格。
- [x] 结果态、设置视图、自定义弹窗在深色主题下可读性正常（对比度足够）。
- [x] 现有功能无回归：生成、复制、下载、产物打开、设置持久化逻辑未变。

## Notes

- 不启用 Tauri 原生 transparent/vibrancy（跨平台风险、无法在本环境验证），磨砂质感由 CSS 分层实现；如后续需要真·透窗，仅需配置级改动。
- 不新增历史记录等功能（YAGNI）。
